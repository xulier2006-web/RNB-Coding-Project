# R&B-Coding-Project
Project Overview: This project is an original R&B music composition created using Python in TunePad. It combines drums, piano, bass and melody at 76 BPM.
Main Features: Drums: Uses functions and loops to create beats with rhythmic variations. Piano: Plays an Am9–Dm9–G13–Cmaj9 chord progression. Bass: Uses different bass patterns to support the rhythm. Melody: Uses four musical phrases to create melodic variation.
How to run a project: Copy the link, click the triangle in the upper right corner to start running the code and play the music. TunePad project link: https://tunepad.com/project/132192#mixer
Project Files: tunepad_project_132192.json   contains the exported TunePad project data and Python code.
References and Acknowledgements: The project uses the TunePad programming environment and its built-in music functions. TunePad: https://tunepad.com
